# ✨ DDCosmetics - Full Stack MERN E-Commerce Platform

A modern cosmetics and skincare e-commerce platform built using the MERN Stack featuring a dedicated Admin Dashboard, Wholesale Portal, Razorpay Payments, Cloudinary Integration, and Progressive Web App (PWA) support.

## 🚀 Live Demo

🌐 Frontend: https://dd-cosmetics.vercel.app

🔌 Backend API: https://ddcosmetics.onrender.com/api

---

# 📌 Features

## 🛍️ Customer Portal

* Product Search, Filter & Sorting
* Shopping Cart & Wishlist
* User Authentication
* Product Reviews & Ratings
* Razorpay Payment Integration
* Order Tracking

## 💼 Wholesale Portal

* Dedicated B2B Product Catalog
* Bulk Pricing Support
* Wholesale Registration

## 🛠️ Admin Dashboard

* Product Management
* Category Management
* Banner Management
* Order Management
* Analytics Dashboard
* Dynamic Branding Control

## 📱 PWA Features

* Installable Mobile/Desktop App
* Offline Support
* Service Worker Caching
* Fast Loading Experience

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/iron-007/DDCosmetics.git
cd DDCosmetics
```

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
